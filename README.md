# Envelopes

A modern, zero-dependency Compose Multiplatform application for generating standard envelope PDFs (#10, #10 windowed, #9, and #6 sizes) with integrated address management, address book, and direct system printing features.

Converted from Python (`env.py`) into pure, idiomatic Kotlin and Compose Desktop.

---

## Key Features

- **Compose Multiplatform UI**:
  - **✉️ Generate Envelope**:
    - Select from configured Return Addresses.
    - Select Envelope Type (#10, #10 Windowed, #9, #6) with real-time descriptions.
    - Recipient Address entry with auto-fill from Address Book.
    - Automatic handling for windowed envelopes (bypasses recipient input).
    - **Real-Time Layout Preview**: Visual scaled envelope preview showing return and recipient address positions.
    - **Actions Under Preview**:
      - **"Print Directly to Printer..."**: Opens the native system print dialog with physical printer/tray selection.
      - **"Generate / Save PDF..."**: Prompts for file destination and writes a standard-compliant PDF.
    - **Automatic Address Book Offer**: When generating or printing for a new recipient, offers to automatically store the contact in your Address Book for future use.
    - **Post-Generation Actions**: "Open PDF" and "Show in Folder".
  - **🏠 Return Address Manager**:
    - Add, edit, delete return addresses.
    - Set primary default return address.
    - Persistent local storage (`~/.envelopes/data.json`).
  - **📖 Recipient Address Book**:
    - Search and filter saved contacts by name, street, city, state, or ZIP.
    - Add, edit, delete contacts.
    - "Use on Envelope" quick-action button.
  - **Desktop Menu Bar**: Full system integration (File, Return Addresses, Address Book, Help).

- **Direct System Printing**:
  - Direct integration with OS print spoolers and print dialogs (`PrinterJob`), rendering anti-aliased text directly to paper without requiring an external PDF viewer.

- **Pure PDF 1.4 Generation**:
  - Standard-compliant PDF output generated byte-for-byte with zero external PDF dependencies.
  - Basic Type 1 Helvetica font styling and accurate geometric layout.

- **Dual Mode**:
  - GUI Mode by default.
  - Headless / CLI Mode via `--cli` argument or in headless terminal environments.

- **Manual Windows MSI & EXE Installer GitHub Action**:
  - Configured with `workflow_dispatch` to build native Windows `.msi` and `.exe` installers on demand via GitHub Actions.

## Running & Building Locally

### Prerequisites
- JDK 17 or higher
- Gradle (wrapper included)

### Launch Compose Desktop App
```bash
./gradlew run
```
*(On Windows: `gradlew.bat run`)*

### Run in CLI Mode
```bash
./gradlew run --args="--cli" --console=plain -q
```

### Run Unit Tests
```bash
./gradlew test
```

### Build Windows MSI & EXE Locally (on Windows)
```powershell
gradlew.bat packageWindowsInstallers
```
The resulting installers will be generated under `build/compose/binaries/main/msi/` and `build/compose/binaries/main/exe/`.

These installers use the custom WiX template in `packaging/windows/main.wxs`: if Envelopes is already installed (any version, including the same one), the installer asks whether to **Replace** it or **Cancel**. Saved addresses in `~/.envelopes` are kept. Compose's built-in `packageMsi`/`packageExe` tasks still work but don't include this prompt.

## GitHub Actions Manual Build Workflow

The workflow at [`.github/workflows/build.yml`](.github/workflows/build.yml) is configured for **manual trigger only** (`workflow_dispatch`):

1. In GitHub, navigate to the **Actions** tab.
2. Select **"Build Windows Installer (Manual)"** on the left.
3. Click **"Run workflow"**.
4. (Optional) Choose whether to publish the build directly as a GitHub release with a tag name.
5. Once complete, download the `.msi` and `.exe` installers from the **Artifacts** section of the run.
